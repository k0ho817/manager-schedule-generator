3개 매장 매니저 월간 근무 스케줄 자동 생성기 파일 역할

1. manager_schedule_generator.py
   - 프로그램 실행 진입점입니다.
   - 여러 후보 스케줄을 생성하고 점수화한 뒤 가장 좋은 후보를 선택합니다.
   - 선택된 스케줄을 검증하고 Excel 파일로 만듭니다.
   - 실행 명령: python manager_schedule_generator.py

2. schedule_config.py
   - 사용자가 직접 수정하는 입력 파일입니다.
   - 연도/월, 후보 생성 개수, 매장별 시프트, 매니저 목록, 공휴일,
     휴무/연차/교육, STL 고정 근무, 예외 고정 배정, 외부 매장 지원 정보를 관리합니다.
   - 나중에 CSV 또는 Excel 입력 방식으로 확장할 때 이 파일을 대체하거나 보강하면 됩니다.

3. schedule_models.py
   - 스케줄 생성에 공통으로 쓰는 상수와 작은 헬퍼를 모아둔 파일입니다.
   - 배정 타입(AUTO, FIXED, STL, UNASSIGNED), 제한값, 배정 데이터 생성 함수를 제공합니다.

4. schedule_utils.py
   - 날짜, 요일, 표시명처럼 여러 모듈에서 반복해서 쓰는 유틸리티 함수 파일입니다.
   - get_month_dates(), date_to_str(), weekday_kr(), is_weekend_or_holiday(),
     manager_display_name() 함수를 제공합니다.

5. schedule_rules.py
   - 근무 가능 여부를 판단하는 규칙 파일입니다.
   - 하루 1근무, 휴무/연차/교육, 공통 근무 가능 여부, 매장A 나이트 제한,
     나이트 다음날 휴무, 마감/나이트 다음날 오픈 금지, 연속근무 제한,
     연속 나이트 제한을 검사합니다.

6. schedule_engine.py
   - 실제 스케줄을 생성하는 greedy 엔진 파일입니다.
   - STL 고정 배정, 예외 고정 배정, 자동 배정, 미배정 방지 강제 배정, 근무 횟수 통계를 처리합니다.
   - strategy 값을 받아 매장 순서, 시프트 순서, 동률 후보 순서를 바꿀 수 있습니다.

7. schedule_selector.py
   - 여러 후보 스케줄을 생성하고 점수화해서 최종안을 선택하는 파일입니다.
   - 전수 탐색 대신 매장 순서/시프트 순서/후보 동률 순서를 바꾼 여러 경우를 빠르게 비교합니다.
   - 점수 기준은 미배정 최소화, 규칙 위반 최소화, 근무 쏠림 최소화입니다.

8. schedule_validation.py
   - 생성된 스케줄의 규칙 위반과 미배정 여부를 다시 검증하는 파일입니다.
   - 고정 배정은 우선 반영하되, 위반 내역은 이 파일에서 찾아 콘솔과 Excel에 출력합니다.

9. schedule_excel.py
   - openpyxl을 사용해 Excel 파일을 생성하는 파일입니다.
   - 매장별 3개 시트, 날짜 세로형 표, 매니저별 통계, 미배정 표시,
     주말/공휴일 행 색상, 검증/예외 사항 출력을 담당합니다.
