Mac 작업 이어받기용 인수인계 메모

프로젝트명
- 3개 매장 매니저 월간 근무 스케줄 자동 생성기

현재 작업 폴더
- Windows 작업 위치: c:\Users\Administrator\Desktop\bkr_schedule
- Mac에서는 이 폴더 전체를 복사해서 사용하면 된다.

실행 명령
- python manager_schedule_generator.py

필요 라이브러리
- openpyxl
- 설치 명령: python -m pip install openpyxl

현재 결과물
- manager_schedule_2026_05.xlsx
- 실행 시 이 파일이 새로 생성된다.

사용자가 처음 요청한 핵심 요구사항
- 한 달치 매니저 근무 스케줄 자동 생성
- Excel(.xlsx) 출력
- 매장별 3개 시트: 매장A, 매장B, 매장C
- 날짜는 세로 방향
- 한 셀에는 한 명만 배정
- openpyxl만 외부 라이브러리로 사용
- 첫 버전은 UI 없이 Python 파일 상단 설정값 수정 방식
- 나중에 CSV/Excel 입력 또는 OR-Tools 방식으로 확장 가능해야 함

매장 및 시프트
- 매장A: 오픈, 데일리, 나이트
- 매장B: 오픈, 마감
- 매장C: 오픈, 마감

인원 규칙
- 모든 매니저는 3개 매장 공통 근무 가능 인원이며 일반 근무 배정 대상
- 매장A: 건대_B, 건대_C, 건대_D
- 매장B: 스타_B, 스타_C
- 매장C: 군자_B, 군자_C
- 각 매장의 B, C는 서로 다른 사람
- 후보 우선순위에서는 특정 매장 소속 인원을 먼저 배정함

STL 규칙
- STL은 매니저가 아닌 별도 인원
- STL_FIXED에 입력된 날짜/매장/시프트에 고정 배정
- STL_FIXED 입력 항목은 date, store, shift만 사용
- STL이 들어간 시프트는 매니저 배정 불필요
- STL 근무는 매니저 통계에 포함하지 않음

고정 배정 규칙
- FIXED_ASSIGNMENTS에 특정 날짜/매장/시프트/worker_id를 입력 가능
- 고정 배정은 자동 배정보다 우선
- 규칙 위반이 있어도 우선 반영
- 위반 내역은 validate_schedule() 결과에 출력

휴무/연차/교육
- OFF_REQUESTS에 매니저별 날짜 목록 입력
- 해당 날짜에는 어떤 매장/시프트에도 자동 배정하지 않음

외부 매장 지원
- SUPPORT_ASSIGNMENTS에 명시된 날짜 + 지원받는 매장 + 시프트를 외부지원으로 고정 배정
- 현재 관리하는 3개 매장 소속 매니저 간 타매장 지원이 아니라 외부 매장에서 받는 지원으로 처리
- 외부지원이 들어간 시프트는 매니저 배정 불필요
- 외부지원 근무는 매니저 통계에 포함하지 않음

공휴일
- HOLIDAYS 리스트에 직접 입력
- 주말/공휴일 근무 균등 분배에 사용
- Excel에서 주말/공휴일 행 색상 표시

적용된 스케줄 규칙
- 매니저는 매장과 무관하게 하루 하나의 스케줄만 가능
- 매장A 나이트는 매장A 소속 매니저와 A만 가능
- 매장A 나이트 다음날은 무조건 휴무 처리
- 마감 또는 나이트 다음날 오픈 금지
- 최대 연속근무 5일
- 연속 나이트 최대 3회
- 모든 매니저 3개 매장 근무 가능
- 본인 소속 매장 우선
- 주말/공휴일 근무 균등 분배
- 전체 근무 수와 시프트별 근무 수 균등 분배
- 미배정 0건을 위해 엄격 규칙으로 배정 불가한 칸은 마지막에 강제 배정
- 강제 배정으로 생긴 규칙 위반은 validate_schedule() 결과에 출력

후보 배정 우선순위
1. 직전 연속근무 일수가 적은 인원 우선
2. 본인 소속 매장 인원 우선
3. 주말/공휴일이면 주말/공휴일 근무 수가 적은 인원 우선
4. 전체 근무 수가 적은 인원 우선
5. 해당 시프트 근무 수가 적은 인원 우선
6. ID 기준 정렬

추가된 기능: 여러 후보 스케줄 비교
- 사용자가 “전체 경우의 수를 보고 선택하는 기능”을 요청함
- 진짜 전수 탐색은 월간 스케줄에서 경우의 수가 너무 커서 현실적으로 어렵다고 설명함
- 대신 여러 greedy 전략을 만들어 후보 스케줄을 여러 개 생성하고 점수화해서 선택하는 기능을 추가함
- 매장 처리 순서, 시프트 처리 순서, 동률 후보 ID 순서를 바꿔 후보를 생성함
- Excel에 "후보요약" 시트를 추가함

후보 선택 설정
- schedule_config.py
- SCHEDULE_OPTION_COUNT = 30
  - 생성할 후보 스케줄 개수
  - 숫자를 키우면 더 다양한 후보를 보지만 실행 시간이 늘어남
- SELECTED_OPTION_INDEX = None
  - None이면 점수가 가장 낮은 후보 자동 선택
  - 특정 후보를 쓰려면 예: SELECTED_OPTION_INDEX = 9

점수 기준
- 낮을수록 좋은 스케줄
- 미배정 수를 가장 크게 불리하게 반영
- 규칙 위반 수를 그다음으로 불리하게 반영
- 전체 근무 수, 주말/공휴일 근무 수, 시프트별 근무 수의 쏠림을 추가 반영
- 시프트별 쏠림은 더 강하게 반영하며, 매장A 나이트는 가능한 인원(A와 매장A 소속)끼리 비교

현재 파일 구조
- manager_schedule_generator.py
  - 실행 진입점
  - 후보 여러 개 생성, 최종 후보 선택, Excel 생성, 콘솔 출력
- schedule_config.py
  - 사용자가 직접 수정하는 설정/입력값
- schedule_models.py
  - 공통 상수, 배정 데이터 생성 헬퍼
- schedule_utils.py
  - 날짜/요일/표시명 유틸 함수
- schedule_rules.py
  - 근무 가능 여부 판단 규칙
- schedule_engine.py
  - greedy 방식의 실제 스케줄 생성 엔진
- schedule_selector.py
  - 여러 후보 스케줄 생성, 점수화, 최종 선택
- schedule_validation.py
  - 규칙 위반 및 미배정 검증
- schedule_excel.py
  - openpyxl 기반 Excel 생성
- FILE_ROLES.txt
  - 각 파일 역할 설명
- HANDOFF_FOR_MAC.txt
  - 이 인수인계 파일

검증 상태
- python -m compileall . 통과
- python manager_schedule_generator.py 실행 성공
- manager_schedule_2026_05.xlsx 생성 확인
- Excel 시트 확인:
  - 매장A
  - 매장B
  - 매장C
  - 후보요약

현재 기본 데이터 실행 결과 예시
- 생성 후보 수: 30
- 자동 선택 후보: 9번
- 점수: 250008
- 미배정: 25건
- 규칙위반: 0건
- 쏠림: 8

현재 미배정이 남는 이유
- 현재 기본 인원 수와 하루 필요 시프트 수가 거의 같음
- 최대 연속근무 5일, 매장A 나이트 다음날 휴무, 마감/나이트 다음날 오픈 금지가 동시에 적용됨
- 그래서 6일차 전후로 인력 공백이 생김
- 코드 오류라기보다 현재 입력 조건에서 발생하는 제약 결과로 보고 있음

Mac에서 이어서 할 때 Codex에게 말하면 좋은 문장
- “이 프로젝트는 bkr_schedule 폴더에 있고 HANDOFF_FOR_MAC.txt를 먼저 읽고 이어서 진행해줘.”
- “schedule_config.py의 입력값을 바탕으로 스케줄 생성기를 개선해줘.”
- “후보요약 시트의 후보를 더 다양하게 만들거나 점수 기준을 조정해줘.”

주의사항
- Windows PowerShell 출력에서는 UTF-8 한글이 깨져 보이는 경우가 있었지만, 파일 자체는 UTF-8로 작성됨
- Mac 터미널에서는 보통 정상 표시될 가능성이 높음
- Mac으로 옮긴 뒤 openpyxl 설치가 필요할 수 있음
